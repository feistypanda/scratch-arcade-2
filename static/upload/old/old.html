Put your scratch game on the

Scratch Arcade!

Instructions:

Prepare your game:

  1. Make a copy of your game so that you can make it compatible with the arcade
  2. Make sure that the copy of your game uses the correct key binds: R is up, D is left, F is down, G is right. S is start, A is action1 (eg shoot), W is action2 (eg speed boost). DO NOT USE Q!!

Package your game:

  1. In the scratch editor, go to file and click save to computer. This should give you your SB3 file.
  2. Go to https://packager.turbowarp.org/. Turbowarp is blocked on the school wifi and school browser, so you will need a VPN and personal browser. Do not try to use a different packager, it will not work
  3. In turbowarp, go to the select project section and choose the SB3 file you downloaded from scratch
  4. After you select the SB3 file, click load project and scroll down to the 'Player Options' section. Make sure that the 'Start project automatically' is selected:
  5. Finally, scroll all the way to the bottom and click package. This will give you your HTML file.

Upload your game:

  1. Uploading your game takes place on the other half of this website
  2. Input the name of your game in the text box. Make sure that the name uses only letters, numbers, spaces, and single quotes. No double spaces.
  3. Input your HTML file
  4. Take a screenshot of your game and make sure it is a png file. Then input that png file. This will be the thumbnail for your game
  5. Upload your SB3 file
  6. Click the upload button. If you followed all the steps correctly, it should say 'Success!'
  7. If you still need help you can send your game to lemilberg@wis.edu and I can do it for you
